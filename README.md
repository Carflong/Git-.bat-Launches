Make sure to launch the .bat files in the folder you have/want your repository

Some info for each .bat is included in their respective folder, under 'info.txt'

----------------------
If you want to create a repository, refer to the 'Initiation' folder.

----------------------
If you want to save, refer to the 'Saving' folder.

----------------------
If you want to remove a file from your repository, use 'Remove File from being Tracked.bat' found in the 'Exclusions' folder.

  If you want to still have that removed file in your personal folders, make sure to add the file to .gitignore using the 'Add to .gitignore.bat' file also found in the 'Exclusions' folder.
  
  If you want to have the .gitignore file ignored, make sure to use the 'Add .gitignore to .gitignore.bat' file also found in the 'Exclusions' folder.

----------------------
If you want to use the GitBash terminal, you can use the 'Terminal.bat' file in the 'Input' folder. It will open the terminal with it already pointing towards the folder you opened it in.

----------------------
If you want to modify your past commits, you can use the 'Modify Commit.bat' file in the "Input' folder.

This has not been thoroughly tested and may result in errors, so use with caution.
  
One issue may be that using it might overwrite files, causing old versions to resurface and new files to disappear. This has not been confirmed.
