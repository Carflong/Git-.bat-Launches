Terminal:
	- Opens a Git Bash terminal already directed to the folder the .bat was opened in


Modify Commit:
	- Allows modification of past commits in the repository

		-Type in a number corresponding to how far back the commit is
			- ie. to get to the commit before your most recent commit, type 2. Type 3 to get to the one before that one, etc.

When you get to the file that pops up, next to the commit(s) you want to modify 'Pick' to the command corresponding to what you want to do, then press save and close it

		 - Make sure to press save for the file (under the 'File' option on the top left of the window) before exiting any files, or else changes will not be saved
		 - Instructions next to # are not read, they are there to inform only)

		 - Commands include:
		 	- [Reword] Allows the commit to be renamed
		 	- [Drop] Deletes the commit
